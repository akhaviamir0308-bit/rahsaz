# Rahsaz 0.50.0-experimental

Experimental build toward the full Rahsaz vision (idea → publish guidance).

## What is real in this build
- Project **Guidance Engine** with stage gates and next action
- **Design** tab (pages + notes + confirm)
- Discovery → Requirements → Architecture → Design → Tasks → AI → Files → Tests → Publish flow
- Manual AI + apply files with **pre-apply snapshot**
- IndexedDB + localStorage, modular engines, quality/publish guides

## What is still partial
- Not a full IDE / E2E test runner / OAuth deploy
- App.tsx still large
- Gates are soft (guide the user; not a hard server lock)

```bash
npm install
npm run build
```
