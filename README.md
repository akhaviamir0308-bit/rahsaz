# Rahsaz v0.21.0

Three-layer product structure:

1. **Learning path** — Academy, overview, discovery (primary for beginners)
2. **Assistant & helpers** — requirements, architecture, tasks, AI center
3. **Specialist tools** — files, preview, versions, publish, settings

- Project creation includes skill level (beginner / intermediate / advanced)
- Beginners open on the Academy tab after creating a project
- Sidebar grouped by the three layers
- Product path banner shows current stage + layer focus

```bash
npm install
npm run build
```
